# Comenzi mese – Maylin Caffe

Notițe de comandă pentru cele 5 mese. Un singur fișier: deschide `index.html` în browser (desktop).

- **+** pe o masă: adaugă produse din meniu (cu căutare); **− / +** schimbă cantitatea.
- **Coș de gunoi**: golește masa, după confirmare.
- **+ Meniu** (dreapta sus): editează, adaugă sau șterge produse.

Datele (meniul și comenzile) se salvează doar în browserul de pe acest calculator.
